# Things Quick Capture for Raycast

A Raycast extension that replicates Things 3's "Quick Entry with Autofill" functionality.

## Why?

The official Things Helper app (`ThingsMacSandboxHelper.app`) can be difficult to install on work machines due to IT restrictions, and Homebrew installation hits the same limitations. This Raycast extension provides the same functionality without those barriers.

## Features

- Captures URL and title from browsers (Safari, Chrome, Brave, Arc)
- Captures email links from Mail and Outlook
- Captures context from Slack and WhatsApp
- Captures file/folder links from Finder
- Captures note links from Notes
- Form UI with project, tags, and scheduling options
- Silent mode for instant capture

## Usage

1. Install via Raycast Store or `bun run dev` for local development
2. Set hotkey to `⌃⌥Space` (Control+Option+Space) to match Things native shortcut
3. For full-screen friendly usage: use Silent command + disable "Show Things Quick Entry" in preferences
